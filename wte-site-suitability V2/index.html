Research transparency

This tool uses the published normalized subindices, not an invented conversion from raw measurements. The published subindices reproduce reported SI to rounding precision; their derivation from raw measurements has unresolved inconsistencies. Recomputed and reported scores are shown separately. This is an educational comparison, not a regulatory or engineering siting approval.

What this project demonstrates

AHP

Python recomputes the three-criterion principal eigenvector and consistency ratio from the report's reciprocal matrix.

Suitability index

SI = Σ(WᵢQᵢ) / ΣWᵢ. Larger scores indicate greater suitability under the selected scoring assumptions.

ANN surrogate

The optional Python experiment trains a new 10–5–1 network on explicitly synthetic data. A linear baseline checks whether a neural network adds value to this weighted linear target.
